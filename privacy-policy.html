Recording Compressor privacy policy

Last updated: 20 August 2026

Recording Compressor processes video entirely on your device. The app does not create accounts, does not include advertising or analytics SDKs, and does not send recordings to a server. If you optionally paste a Google Gemini API key and use “Generate extra args,” only the text prompt and encode settings are sent to Google. The video file is not uploaded.

Data the app uses

  • Videos you import or record, stored in app cache and, after compression, in Movies/RecordingCompressor on the device.
  • Optional microphone audio, only when you enable microphone capture.
  • Optional internal playback audio (Android 10+), only when you enable internal capture. You can capture all media/game playback or limit capture to one app you pick.
  • Optional camera inset (front or rear) while recording, only when you turn it on. The preview is part of the captured video.
  • Optional tap, laser, or ink overlay. If you enable the accessibility service for this purpose, it only draws during a recording. It does not read on-screen text or passwords.
  • Optional overlay windows (region selector, camera inset, floating pause/stop, status-bar cover) that require “Display over other apps.”
  • Job history (file names, sizes, status) stored locally in an on-device database.
  • If you turn on “Delete original after compress,” the app attempts to remove the source video after the compressed copy is saved. This stays on the device and is never uploaded.
  • Optional Gemini API key, stored locally, used only when you ask Gemini to write extra FFmpeg arguments.
  • On Android 16 and later, a privileged system assistant (for example Gemini, when that integration is enabled) may call this app’s App Functions to list jobs, change encode settings, start or wait for encodes, share or open a finished file with the system sheet, discard history rows, and read progress or encode logs. Those functions return metadata only, not the media files. Sharing uses Android’s share sheet; this app does not upload the file. The assistant may process your spoken request on a server; this app still does not upload recordings.
  • Optional device library access (photos, videos, and audio). If you turn this on in Settings and choose Allow all, the app and a privileged assistant can list and open media already on the device without using the system picker. You can revoke this in Android Settings.

Permissions

  • Internet — only for the optional Gemini extra-args generator. Encoding and recording stay on-device.
  • Screen capture — Android MediaProjection consent, requested every recording session.
  • Microphone — only if you record microphone or mixed mic + internal audio.
  • Camera — only if you turn on the camera inset while recording.
  • Display over other apps — region selection, camera inset, and floating recording controls.
  • Accessibility — optional, only to draw tap ripples, a laser pointer, or ink during recording. Not used to read content.
  • Nearby devices / Bluetooth — only if you pick a Bluetooth microphone while recording.
  • Notifications — progress for recording and compression that continue when you leave the app.
  • Quick Settings tile — start, pause, or resume a recording from the system shade (screen-capture consent still appears).
  • Photos, videos, and audio — optional. Used only after you enable Device library access so the app or an assistant can open files already on the device. The system picker and Share still work without this.

You can keep using the system picker and Share without granting library access.
